# CalculaTudo

Plataforma para cálculos do dia a dia, incluindo conversão de moedas, IMC, TMB e consumo de água.

## Sobre o Projeto

O CalculaTudo é uma aplicação web desenvolvida com Next.js que oferece quatro calculadoras principais para facilitar o dia a dia:

1. **Conversor de Moedas** - Converta valores entre diferentes moedas com taxas atualizadas
2. **Calculadora de IMC** - Calcule seu Índice de Massa Corporal e descubra sua faixa de peso
3. **Calculadora de TMB** - Descubra sua Taxa Metabólica Basal e necessidades calóricas diárias
4. **Calculadora de Consumo de Água** - Calcule a quantidade ideal de água que você deve consumir

## Tecnologias Utilizadas

- **Next.js** - Framework React para desenvolvimento web
- **TypeScript** - Linguagem de programação tipada
- **Tailwind CSS** - Framework CSS para design responsivo
- **Jest** - Framework de testes
- **React Testing Library** - Biblioteca para testes de componentes React

## Recursos

- Interfaces modernas e responsivas
- Acessibilidade (WCAG) com suporte a leitores de tela e navegação por teclado
- Modo de alto contraste e ajuste de tamanho de fonte
- Integração com API de moedas para taxas de câmbio em tempo real
- Testes unitários para garantir a qualidade do código

## Como Executar Localmente

1. Clone o repositório:
```bash
git clone https://github.com/seu-usuario/calculatudo.git
cd calculatudo
```

2. Instale as dependências:
```bash
pnpm install
```

3. Execute o servidor de desenvolvimento:
```bash
pnpm dev
```

4. Acesse a aplicação em `http://localhost:3000`

## Testes

Para executar os testes:

```bash
pnpm test
```

## Deploy

A aplicação pode ser facilmente implantada na Vercel:

1. Faça fork deste repositório
2. Conecte-se à Vercel (vercel.com)
3. Importe o projeto do GitHub
4. A Vercel detectará automaticamente que é um projeto Next.js e configurará o build
